# 🚀 Enable GitHub Pages - Quick Guide

Your portfolio has been pushed to the `main` branch! Now enable GitHub Pages:

## Quick Steps:

1. **Open GitHub Pages Settings:**
   - Go to: https://github.com/gagan-malik/gaganmalik.github.io/settings/pages

2. **Configure Source:**
   - Under "Source", select:
     - **Branch:** `main`
     - **Folder:** `/ (root)`
   - Click **"Save"**

3. **Wait & Visit:**
   - Wait 1-2 minutes for GitHub to deploy
   - Visit: **https://gaganmalik.github.io**

## Current Repository Status:

- ✅ **main branch** → Your portfolio (just pushed!)
- 📚 **gh-pages branch** → Design system documentation

## Note:

Since you already have a `gh-pages` branch with Storybook docs, you have two options:

### Option A: Portfolio as Main Site (Recommended)
- Portfolio: `https://gaganmalik.github.io` (from `main` branch)
- Design System: Keep in `gh-pages` branch but change the Pages source to `main`

### Option B: Keep Both Separate
- We can set up the design system at a subpath like `/design-system`
- Portfolio stays at the root
